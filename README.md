# Автомашины дугаар танигч

PlateScope — зураг, видеоноос улсын дугаар таньж, улсын таамгийг харуулан SQLite санд бүртгэдэг Streamlit апп.

## Интерфэйс

- Хажуугийн цэсээр таних самбар, бүртгэлийн түүх, тусламжийн хооронд шилжинэ.
- Зураг, видео болон танилтын үр дүнг зэрэгцүүлэн харуулна. Хадгалалт амжилттай болсны дараа «Бүртгэгдлээ» мэдэгдэл гарна.
- Нийт бүртгэл, өнөөдрийн танилт, бүртгэлтэй улс, дундаж OCR оноог бодит сангаас тооцно.
- Түүхээс дугаараар хайж, улсаар шүүж, эрэмбэлж, хуудсаар үзэн CSV татаж болно. Дэлгэц болон CSV-д урт файлын нэр орохгүй.
- Хуудас хооронд шилжих, шүүлтүүр өөрчлөх үед сүүлийн үр дүн хадгалагдаж, автоматаар давхар бүртгэл үүсэхгүй.
- Улсыг нэр болон кодоор нь ялгана: **Монгол · MGL**, **Япон · JPN**, **АНУ · USA**, **Өмнөд Солонгос · KOR**, **Герман · DEU**. Код нь үр дүн, түүх болон CSV-д харагдана.

`aajil.py` нь ажиллуулах файл, `plate_core.py` нь танилт ба хадгалалт, `dashboard.py` нь интерфэйс, `.streamlit/config.toml` нь өнгө ба загварын тохиргоо.

## Суурилуулалт

Python 3.10–3.13 ашиглана.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m ensurepip --upgrade
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Ажиллуулах

Аппыг ажиллуулах:

```powershell
.\.venv\Scripts\python.exe -m streamlit run aajil.py --server.port=8501
```

Эхний удаа илрүүлэгч болон OCR загварууд интернэтээр татагдана. Үндсэн сонголт **Монгол дугаар**: энгийн 4 тоо + 3 үсэгтэй дугаарыг кирилл OCR-оор уншина. `MGL` тэмдэг заавал харагдах шаардлагагүй. Өнгөт, контраст сайжруулсан, хар-цагаан хувилбаруудаас хамгийн багадаа хоёрт нь ижил дугаар уншигдаж, өөр дугаартай зөрөөгүй бол оноог харуулна. Энэ тохирол нь зөв уншсаны баталгаа биш.

**Гадаад дугаар** сонголтоор өмнөх олон улсын танилтыг ашиглана. Монгол горимд Япон, Солонгосын нэмэлт OCR ачаалахгүй. Тусгай болон хуучин дугаарын форматууд Монгол горимын үндсэн шалгалтад орохгүй.

Хоёр мөртэй Монгол дугаарт дээд талын 4 тоо, доод талын 3 үсгийг байрлалаар нь нийлүүлнэ. Өндөр харьцаатай дугаарын хэсгийг дээд/доод хагаст хуваан OCR-оор нэмэлт уншуулна. Энэ нь бүх хоёр мөртэй зураг дээр зөв унших баталгаа биш.

Кирилл OCR дугаар уншаагүй бол хүрээг бага зэрэг тэлж дахин оролдоно. Дахин уншигдахгүй бол FastALPR-ийн бэлэн OCR хариуг зөвхөн Монгол дугаарын формат таарсан үед ашиглана. Зураг оруулахад EXIF эргэлтийг засна.

Уншигдсан дугаар бүрийг онооноос үл хамааран автоматаар хадгална. Видеонд боловсруулсан кадр бүрийн уншилтыг нэмэх тул ижил дугаар давтан бүртгэгдэж болно. Дугаарын текст огт уншигдаагүй бол хоосон бүртгэл нэмэхгүй. Танилтын мэдээлэл `plates.db` SQLite файлд хадгалагдана. Замыг `PLATE_DB` орчны хувьсагчаар өөрчилж болно.

Браузераар http://localhost:8501 нээнэ.

## Интерфэйсийн шалгалт

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Шалгалтууд тусдаа түр сан ашиглаж, зураг оруулах, хадгалалт, давхар бүртгэлээс сэргийлэх, видео, хайлт, хуудаслалт, алдаатай файл болон хоосон үр дүнг шалгана. OCR-ийн үр дүнг эдгээр шалгалтад орлуулдаг; бодит таван улсын зургийн танилтын өмнөх үр дүнг `verification_report.md`-ээс үзнэ.

## Dataset бэлтгэх ба YOLO сургах

1. Roboflow Universe-ээс license plate detection dataset-ийг **YOLOv8** форматаар экспортолж `data/plates/` дотор байрлуулна.
2. Dataset-ийн `data.yaml` дахь `path`, `train`, `val` замыг энэ төслийн `data/plates.yaml`-тай тааруулна. Зөвхөн нэг ангитай байх бөгөөд `names: {0: license_plate}` байна.
3. Монгол дугаарын төрөл, өнцөг, гэрэлтүүлэг, зай, цаг агаарын ялгаатай өөрийн зургуудыг нэмнэ. CVAT эсвэл Label Studio-д бүх дугаарын гадна хүрээг rectangle хэлбэрээр тэмдэглэж, YOLO format-аар экспортолно. Train/validation/test-д ижил машины ойролцоо кадрууд давхар орохгүй байхаар салгана.
4. Зураг бүрд ижил нэртэй `.txt` файл, мөр бүрд `class x_center y_center width height` (0–1 нормчилсон) байна. Хоосон label файл нь дугааргүй зургийг илэрхийлнэ.
5. Сургалт эхлүүл:

```powershell
python aajil.py train --data data/plates.yaml --model yolov8n.pt --epochs 100 --imgsz 640
```

Жижиг dataset-д `--batch 8` хэрэглэж болно. Сургалтын `best.pt`-ийг `PLATE_MODEL` болговол `load_models()` функцээр ашиглаж болно. Одоогийн UI нь FastALPR илрүүлэгчийг ашигладаг тул өөрийн сургасан YOLO-г UI-д холбох нэмэлт өөрчлөлт шаардлагатай. Roboflow болон бусад эх dataset-ийн лиценз/ашиглах нөхцөлийг тус бүр шалгана.

## Улс танилт ба хязгаарлалт

Япон, Өмнөд Солонгос, АНУ, Монгол, Герман болон global загварын бусад улсыг хамруулна. АНУ, Герман нь global загварын ангилалд ордог. Японы ханз/кана, Өмнөд Солонгосын хангыль ба энгийн дугаарын бүтэц, Монголын `MGL` тэмдэг ба кирилл үсгийг тусгай OCR-оор давхар шалгана. Улсын нэрийг Монгол хэлээр харуулж, үр дүнг `country` баганад хадгална.

Дугаараас тусдаа тод уншигдсан улсын тэмдэг нь global загварын таамгаас түрүүнд үйлчилнэ. `MGL` уншигдсан ч дугаарын текст бүрэн нийлээгүй үед Монгол гэсэн улсыг хадгална. Монголын хоёр мөртэй дугаарын тоо, үсгийг тусад нь уншиж нийлүүлнэ. Зөвхөн дөрвөн тоо, гурван латин үсэг таарсан шалтгаанаар Монгол гэж оноохгүй. Тэмдэг, бичгийн нотолгоо хоорондоо зөрөх эсвэл global улсын оноо 0.75-аас доош, өөр нотолгоогүй бол «Тодорхойгүй» гэж харуулна. Энэ босго нь магадлалын баталгаа биш.

OCR нь RapidOCR/ONNX Runtime ашиглана. Япон, Солонгос, кирилл загварууд эхний удаа `models/rapidocr/` хавтаст татагдана. UI танилт PyTorch ашиглахгүй; `train` командын Ultralytics тусдаа PyTorch шаарддаг.

Бүх улсын бүх төрлийн дугаарыг баталгаатай танихгүй. Хуучин, дипломат, тусгай дугаарын формат болон бүдэг зурагт алдаа гарч болно. Global загвар дэмждэггүй улсыг өндөр оноотой өөр улсаар андуурах боломжтой. Нэмэлт OCR-ууд хоорондоо зөрвөл `Тодорхойгүй` гэж харуулна. Загварын оноог бодит үнэн зөвийн магадлал гэж үзэхгүй.
